# NYC Traffic Crash Analysis

## 📊 Project Overview

This project analyzes New York City traffic crash data to identify trends, patterns, and factors contributing to road accidents and injuries across the city.

The analysis was developed as a data analytics and business intelligence project using **Power BI**, with the goal of transforming raw traffic crash data into meaningful insights that can support better understanding of road safety patterns.

## 🎯 Project Objectives

The project aims to answer key questions such as:

* Are traffic crashes increasing or decreasing over time?
* Which boroughs experience the highest number of crashes?
* Which streets and intersections are most dangerous?
* What are the leading causes of traffic crashes?
* Which groups are most affected by traffic crashes?
* How do injuries vary among motorists, pedestrians, and cyclists?

## 🛠️ Tools & Technologies

* **Power BI** – Data transformation, modeling, analysis, and visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and calculations
* **Microsoft Excel/CSV** – Data preparation and source data

## 📁 Dataset

The project uses NYC traffic crash data containing information about traffic collisions, locations, contributing factors, vehicles involved, and injuries.

The dataset was cleaned and transformed before being loaded into Power BI for analysis.

## 🔄 Data Preparation

The data preparation process involved:

1. Cleaning missing and inconsistent values
2. Removing unnecessary fields
3. Transforming columns into appropriate data types
4. Creating calculated fields and measures
5. Building relationships between relevant tables
6. Developing KPIs for crashes and injuries
7. Creating interactive visualizations

## 📈 Dashboard

The Power BI dashboard provides an interactive view of NYC traffic crashes, allowing users to explore crash trends, locations, causes, and injury patterns.

### Key Dashboard Areas

* Total Traffic Crashes
* Total Injuries
* Crash Trends Over Time
* Crashes by Borough
* High-Risk Streets and Intersections
* Leading Contributing Factors
* Injury Distribution
* Motorist, Pedestrian, and Cyclist Analysis

## 🔍 Key Insights

The analysis highlights important patterns in NYC traffic crashes, including differences in crash frequency across boroughs, major contributing factors, and the groups most affected by traffic-related injuries.

*Detailed findings are presented in the Power BI dashboard and project documentation.*
